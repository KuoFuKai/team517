Task normal flow: DRAFT -> OPEN -> HAS_OFFERS -> AWAITING_CONFIRMATION -> ARRANGED -> IN_PROGRESS -> COMPLETION_PENDING -> COMPLETED. CANCELLED and DISPUTED are exception states. Future no-show direction is recorded in product-policy.md; grace periods, evidence and implementation remain undecided.

Before confirmation, backups stay ACTIVE and pending decline/requester cancellation falls back to HAS_OFFERS or OPEN. Confirmation closes backups as NOT_SELECTED. Cancelling a confirmed arrangement reopens OPEN, without reviving stale backups. Cancelling the Task closes pending/confirmed arrangements atomically. Execution cannot be normally cancelled in this Sprint.
